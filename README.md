## 🔬 What is an ICSR?

An **Individual Case Safety Report (ICSR)** is a standardized document used to report information about a **single patient's adverse drug reaction** to regulatory authorities and pharmacovigilance databases.

| Feature | Details |
|---------|---------|
| **Full name** | Individual Case Safety Report |
| **Purpose** | Document & report a single ADR event for regulatory review |
| **Used by** | Pharmaceutical companies, hospitals, regulatory agencies |
| **Submitted to** | WHO VigiBase, CDSCO/PvPI (India), FDA MedWatch, EMA EudraVigilance |
| **Format standard** | ICH E2B(R3) — international data standard |
| **Trigger** | Any serious or unexpected ADR event |

### ICSR vs Other Reports

| Report Type | Scope | Frequency |
|-------------|-------|-----------|
| **ICSR** | Single patient, single event | Per event |
| **PSUR** | All cases for a drug | Periodic (6 months/1 year) |
| **SUSAR** | Serious unexpected in clinical trials | Per event (7–15 days) |
| **Signal** | Pattern across multiple ICSRs | Ongoing monitoring |

## 📚 Key Learnings

- ✅ An **ICSR is the foundation** of pharmacovigilance — every drug safety decision starts with individual case reports
- ✅ A Drug Safety Associate must master **all 4 domains**: identification, reporting, causality, and classification
- ✅ **ICH E2B(R3)** is the international standard format for ICSR data submission
- ✅ **MedDRA coding** (Medical Dictionary for Regulatory Activities) is used to standardize reaction terms
- ✅ Even **non-serious ADRs** must be reported — they contribute to signal detection over time
- ✅ **Causality + Seriousness + Expectedness** together determine the urgency and type of regulatory action
- ✅ Accurate reporting today → **safer medicines tomorrow**
- ✅ This internship simulated real-world workflows used by Drug Safety Associates in pharma companies globally
